# Interactive Truth Table Generator

## Project Overview
This is an individual project developed for CS245 – Discrete Structures at Southeast Missouri State University.

The project is a Python-based interactive truth table generator that evaluates propositional logic expressions and generates truth tables automatically.

## Features
- Accepts user-input logical expressions.
- Supports logical operators such as AND, OR, NOT, and IMPLIES.
- Generates truth tables for different combinations of truth values.
- Evaluates logical expressions using Reverse Polish Notation (RPN).
- Classifies expressions as tautologies, contradictions, or contingencies.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- Itertools
- Regular Expressions

## How to Run
1. Download the `truth_table_generator.ipynb` file.
2. Open it in Jupyter Notebook or Google Colab.
3. Install Pandas if it is not already available.
4. Run the notebook cells in order.
5. Enter a propositional logic expression when prompted.
